## Changes

- Fixed `history.go` (and back/forward) so ignoring navigation blockers now works consistently, and unsaved-changes warnings are correctly restored after a blocked history jump.
- Fixed a type-checking error that could appear for consumers with strict library type-checking enabled, caused by a stray internal reference in the published types.
- Fixed inline styles and scripts in the page head being needlessly rewritten on every client-side navigation, which caused a full stylesheet reparse and could crash pages enforcing a strict script-security policy (breaking change if you rely on that content being replaced each render).
- Fixed route lifecycle callbacks (enter/stay/leave) incorrectly firing for hidden routes nested below an active error or not-found boundary.
- Error boundaries now accept and display any thrown value, not just Error objects, so falsy or unusual thrown values no longer break the error UI; existing code that assumes the caught value is an Error should add a type check before reading its properties (breaking change).
- Fixed navigation away from a "not found" page sometimes losing its boundary and context while the next page's data was still loading.
- Fixed route-scoped versions of the match/search/params hooks ignoring the option to return undefined instead of throwing for inactive routes.
- Reduced unnecessary promise allocations during client-side navigation and server rendering, speeding up navigation with many hooks or cached routes.
- Sped up absolute-URL detection used by links, navigation, and redirects.
- Replaced the internal route-resolution cache with a more memory- and CPU-efficient eviction strategy, speeding up repeated navigations.
- Reduced quadratic slowdowns when committing navigations with many cached/preloaded routes.
- Skipped unnecessary JSON-parsing attempts on search-parameter strings that can't be valid JSON, speeding up search parsing.
- Fixed a navigation-queue leak where rapid back-to-back navigations kept superseded navigations alive and caused increasingly slow settling.
- Sped up build times for Start apps using the Rsbuild bundler by making import-safety checks lazier and cheaper.
- _Plus 2 chore / dependency / other-framework / test updates, not detailed._
