## Changes

- Updated the devtools theme integration to a newer internal API, with no change expected for users.
- Fixed a bug where async and sync queues silently dropped falsy items like zero, empty string, or false, and no longer crash when a null item is added without custom priority logic.
- Fixed async queues to properly respect their configured wait period even when new items are added while processing is active, instead of sometimes bypassing the delay.
- Fixed async queue processing so a failing task no longer breaks the whole queue or causes unhandled errors, and flushing now correctly resumes interrupted processing.
- Fixed a memory leak where every debounced, throttled, rate-limited, or queued async execution left behind a permanent internal tracking entry that was never cleaned up.
- Fixed async debounce, throttle, and rate-limit utilities so their results and callbacks return the actual resolved value instead of an unnecessarily wrapped promise (breaking change for TypeScript users relying on the old wrapped return type).
