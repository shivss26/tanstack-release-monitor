## Changes

- Fixed a bug where subset data loads or sync collections could report success before the underlying rows were actually visible, and cancelled loads could no longer overwrite results that came after them.
- Equivalent data queries that only differ in ordering, aliasing, or condition order are now recognized as the same request, so cached or in-flight results are reused instead of duplicated work.
- Creating a new collection descriptor with an id matching an existing one now reuses the existing collection instead of creating a duplicate, making it safer to recreate dynamic collections across renders.
