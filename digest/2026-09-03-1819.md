## Changes

- All provider adapters (Gemini, Cohere, ElevenLabs, Mistral, Ollama, Bedrock) now accept a common base URL and default headers option, so a single gateway or proxy config can be reused across adapters without renaming fields for each vendor; existing vendor-specific option names still work.
- Fixed an intermittent failure where OpenAI reasoning-model tool loops would error out on the follow-up turn because required reasoning context wasn't being resent with the tool call.
- Requests to OpenAI reasoning models now include extra reasoning detail by default (needed for the above fix), while older non-reasoning chat models are unaffected.
