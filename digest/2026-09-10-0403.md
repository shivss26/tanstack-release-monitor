## Changes

- Blocks unsafe or malformed URLs in navigation, links, redirects, and prerendering, closing gaps where dangerous or protocol-relative destinations could be used (breaking change if you relied on unnormalized origins or the removed URL-check helper).
- Fixes a crash when a rewrite sends an in-app navigation to a different origin by falling back to a full page reload instead of throwing an error.
- Speeds up building query strings by skipping unnecessary work when there are no search parameters to serialize.
- Reduces unnecessary work when resolving link styling/state, slightly improving link rendering performance.
- Speeds up route cache cleanup after navigation, especially for apps with large caches or deep route trees.
- Speeds up Start builds by skipping collection of unused build/manifest data and inline CSS content when inlining is disabled.
- Reduces overhead for links without custom event handlers, cutting unnecessary allocations during rendering.
