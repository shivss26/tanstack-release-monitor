## Changes

- Chat and generation hooks now support letting end users paste their own provider API keys in the browser, sent securely without ever touching your server-side environment variables.
- Added a new adapter for the Lovable AI Gateway, covering chat, embeddings, image, video, speech, and transcription, plus the bring-your-own-key flow.
- Fixed a bug where extra per-message data passed when sending a chat message was silently dropped instead of reaching the server.
- Fixed bring-your-own-key requests using the wrong provider's key when a message temporarily overrode the provider for a single call.
- Fixed a bug where a delayed/late interrupt response could incorrectly overwrite chat state after the chat had already been reset or reloaded.
- Fixed an issue where a tool-input validation error handled entirely on the server could incorrectly trigger a redundant extra request from the client.
- Fixed canceling a pending tool-approval request failing when the tool had since been removed or its input requirements changed.
- Added Svelte support for the AI Devtools panel (no change for React users beyond an internal dependency update).
- Refreshed the built-in model metadata list to reflect the latest models available from OpenRouter and Vercel AI Gateway.
- Fixed reasoning/thinking output being silently dropped for older OpenAI-compatible providers (such as certain Amazon Bedrock endpoints) that still use a legacy streaming event name.
- Fixed a Gemini bug where an unexpected tool-call finish could emit duplicate tool-call events and crash the chat run entirely.
