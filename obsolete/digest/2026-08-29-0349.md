## Changes

- Added a new package that automatically trims or summarizes long chat histories so conversations stay within a model's context limit, with a few interchangeable strategies (drop oldest messages, summarize them, or clear old tool results) that can be combined.
- Chat history sent to the model can now be kept separate from the full saved conversation, letting old compaction work be reused instead of redone.
- Middleware steps can now send progress updates to the client while they're still running, instead of only after they finish; custom middleware code may need to be updated to account for this new capability (breaking change).
- The DevTools panel now shows a dedicated view of context-compaction activity, including before/after message counts and which messages were kept or dropped.
- Fixed structured-output schema conversion so multi-part tuple definitions keep all their entries instead of losing everything after the first one.
- Refreshed the built-in list of available AI models and their metadata to match the latest data from providers.
