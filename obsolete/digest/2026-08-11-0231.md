## Changes

- Added a new activity to generate vector embeddings from text and images across many providers, useful for search and similarity features.
- Added a new activity to rerank a list of documents by relevance to a query, supported by Cohere and OpenRouter.
- Added a Bun-native driver for running sandboxed code faster and more reliably in Code Mode on Bun servers.
- Added a Daytona sandbox driver so Code Mode can execute untrusted code in caller-owned Daytona sandboxes.
- Added support for the Seedance 2.5 video model with its full set of duration, resolution, and audio options.
- Media generation actions (image, audio, video, speech, transcription, summarize) now support timeouts and cancellation so hung requests can be aborted instead of hanging forever.
- Fixed message IDs being lost when converting chat UI messages into the format used for saving/persisting conversations.
- Fixed usage/token-count reporting so it now reflects totals across an entire multi-step chat run instead of just the last step.
- Fixed message creation timestamps being lost when converting and persisting chat messages, so restored conversations keep their original times.
- Fixed error reporting so HTTP status codes are preserved for providers (like Google) that report errors without a separate error code, instead of showing an unknown error.
- Fixed incorrect type suggestions for provider-specific options on text-to-speech, transcription, and summarization requests.
- Fixed a bug where resuming an interrupted chat could leave the UI stuck showing "generating" when the provider's response didn't include a proper completion signal.
- MCP tool connections can now be configured with custom validation settings, fixing a crash that occurred when using MCP tools on Cloudflare Workers.
- MCP tools now carry over descriptive titles and safety hints (like whether a tool is read-only or destructive) from the server, so host apps can label and gate tool approvals better.
- Mistral vision models can now accept PDF documents as input, not just images and text.
- Fixed a bug in the Anthropic adapter where a caching option was silently dropped instead of being sent to reduce costs.
- Fixed tool-call tracking IDs sometimes getting mixed up during multi-step tool use with OpenAI/OpenRouter's Responses API, which could break follow-up requests.
- Added text summarization support for Groq, matching what's already available for other providers.
- Fixed internal package version ranges so upgrading one TanStack AI package no longer risks pulling in duplicate copies or unresolvable version conflicts of another.
